# 历史抉择推演

面向现实人生、商业、关系与职业决策的古籍案例推演技能。

核心资料库：《史记》《资治通鉴》。

工作链：现实困境 → 抉择结构 → 原典检索 → 正反历史案例 → 当时信息集 → 选项/结果/代价 → 跨案例规律 → 现实决策树。

详细规范见 `SKILL.md`。

主要证据源：
- Chinese Text Project《史记》：https://ctext.org/shiji
- Chinese Text Project 古籍检索：https://ctext.org/searchbooks.pl
- Library of Congress《资治通鉴》数字藏本：https://www.loc.gov/item/2021666361/

原则：原典优先、出处可核验、禁止结果论、强制反例、史实与推断分层。
